### Narra-Notch v2.2.0

Initial full-stack release of Narra-Notch with complete desktop and mobile companion support.

### Highlights

- **Desktop Dynamic Island Notch**: Live activities, media player controls, synchronized lyrics with latency calibration, quick converters, system monitors, and notifications on Windows.
- **Coding Agent Integration**: Antigravity & OpenCode live monitoring, real-time diff viewer, and instant tool execution approvals (Allow / Always / Deny).
- **Dedicated Chat Workspaces**: Independent toggles and dedicated quick-launch cards for Antigravity and OpenCode across desktop and mobile companion.
- **Mobile Companion App**: PWA, Android, and iOS companion with seamless LAN hook synchronization, realtime status notifications, and isolated OpenCode chat pairing.
