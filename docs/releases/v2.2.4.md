### Narra-Notch v2.2.4

The Antigravity chat now looks and behaves exactly like the OpenCode chat, and its model list is read live from the Antigravity CLI instead of being hardcoded.

### Highlights

- **Antigravity chat = OpenCode chat**:
  - Rebuilt the renderer to mirror `OpenCodeSessionView` one-to-one: session picker with search, quick **New session** and **Refresh** buttons, the **Model + Effort** pill row, emerald user bubbles, sky-bordered assistant bubbles, and the same composer/footer.
  - Works on desktop and in the mobile companion (`AgentChatBox mobile`), including the pairing and expand controls.
- **Auto-detected models**:
  - `get_available_models_internal()` now runs `agy models`, parses `id<TAB>display name`, and groups the results into base models with their effort variants. On the reference machine that yields 18 models (`gemini-4-argon-*`, `gemini-4-hydrogen-*`, `gemini-3.8-flash-*`, `claude-opus-5-5-*`, `claude-sonnet-5-5-*`, `gpt-oss-120b-medium`, `gemini-pro-orchestrator-g1-pro`).
  - Results are cached for 5 minutes, bounded by an 8-second timeout, and fall back to the bundled list — the command runs on a blocking thread so the UI never freezes.
  - The mobile `/api/models` endpoint uses the same detection path.
- **Polished model picker**:
  - Searchable list with category labels and a check mark on the active model.
  - Effort picker shows only the variants that exist for the selected base model.
  - If a previously selected model disappears between runs, the selection snaps to the first valid model instead of sending a dead id.
- **Preview data**: the browser showcase now seeds the real detected model list, sample sessions, and supports `agentSubTab=chat` / `mobileTab=chat` so the layout can be reviewed without the Tauri backend.
