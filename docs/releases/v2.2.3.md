### Narra-Notch v2.2.3

A quick polish release fixing mobile layout overflow and bottom dock overlap in the Glisse Liquid Glass companion interface.

### Highlights

- **Mobile Layout & Overflow Fixes**:
  - Compacted the `glisse` `SegmentedControl` (`56px` segments) so **Light / Dark / Auto** (and **Terang / Gelap / Otomatis**) fit cleanly inside the Settings row without overflowing horizontally.
  - Balanced the Mochi mascot stage height (`208px`), tightened Settings row spacing, and gave `.ca-sh` proper bottom clearance (`82px + safe-area`) with dedicated inner scroll containers so rows (including **Settings → About**) never collide with or hide under the floating bottom `TabBar`.
  - Refined `glisse` `TabBar` backdrop blur (`20px`) and glass contrast for both Light and Dark themes.
