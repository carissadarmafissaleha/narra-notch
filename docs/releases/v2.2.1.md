### Narra-Notch v2.2.1

A refined update bringing a redesigned mobile companion interface, file uploads in OpenCode mobile chat, enhanced agent sound controls, and fresh high-resolution dark gradient showcases.

### Highlights

- **Redesigned Mobile Companion Interface**:
  - Enlarged Mochi mascot arena with crisp 60 FPS interactive physics and preserved touch gestures.
  - Fluid bottom dock navigation with spring-animated active tab indicators (`Terminal` → `Diff` → `Antigravity` → `OpenCode`) that auto-resize dynamically when chat tabs are toggled.
  - Page transition animations via `AnimatePresence` and cleaned overview screen without duplicate chat buttons.
- **OpenCode Enhancements**:
  - Direct file attachment uploads in mobile agent chat.
  - Mobile pairing view with 8-character input blocks matching desktop companion security.
  - Dedicated chat bubble icon for OpenCode sessions.
- **Controls & Usability**:
  - Enlarged and ergonomically improved sound volume slider in Coding Agent settings.
  - Quick Dark / Light mode toggle directly beside the settings gear in the mobile header.
  - Quick Turbo Mode header pill toggle and dedicated switch inside settings.
- **Studio Documentation & Showcase**:
  - Fresh media gallery with premium dark gradient desktop mockups and full English UI localization.
