### Narra-Notch v2.2.2

This release brings Apple-style Liquid Glass mobile controls (`glisse`), full UI & Model/Effort picker parity between Antigravity and OpenCode chat, instant mobile state resync, stricter pairing code protection, and bilingual (English & Bahasa Indonesia) documentation including a Windows Smart App Control / SmartScreen installation guide.

### Highlights

- **Liquid Glass Mobile UI (`glisse`)**:
  - Upgraded the mobile companion dock to `glisse`'s Liquid Glass `TabBar` with spring & lens drag physics, `SegmentedControl` for theme selection, `Switch` toggles, and glass action buttons.
  - Replaced heavy lower sheet outlines with a dynamic inner radial gradient synchronized live with Mochi's state color (idle, working, approval, finished).
  - Enlarged Mochi stage (`215px`), converted Wardrobe outfit selection into a clean dropdown menu, slimmed the header with an inline `Connected` status badge, and moved the version footer into **Settings → About**.
- **Antigravity & OpenCode Chat Parity**:
  - Unified Antigravity Chat UI (`AgentChatBox`) with OpenCode styling and controls across desktop and mobile, exposing live **Model** and **Effort** selectors detected from `/api/models`.
- **Pairing Gate & Reliable Sync**:
  - Enforced the 8-character pairing token check across `/api/models` alongside chat, history, upload, and OpenCode endpoints.
  - Fixed a cold-start & resume sync issue on mobile so `/api/status` automatically syncs whenever the companion connects or regains focus.
- **Bilingual Documentation (`EN | ID`)**:
  - Updated `README.md` with clear **English & Bahasa Indonesia** explanations covering Windows Defender SmartScreen and Windows 11 Smart App Control installation steps.
